# Demo prompts

What to type during the demo, in order. Lines in code are messages; lines in brackets are taps. Full script with voice-over: [demo.md](demo.md).

1. *(onboarding: type a name, set the location to **شیخ هادی**)*
2. `یه گوشی ساده برای مامانم`
   *(pick a Nokia from the choices, then tap a pin on the map)*
3. *(on the shop list: «کی می‌ری؟» → «امروز عصر», toggle «الان باز», drag the radius or budget)*
4. `سه تای اول رو با هم مقایسه کن`
5. `از اولی بپرس موجود داره یا نه`
   *(tap «فرستادم», then paste the shop's reply:)*
   `تموم کردیم`
6. `برنامه‌ی رفتن به دوتای بهتر رو بچین`
   *(tap «بفرست برای کسی», then turn on airplane mode and reload to show it works offline)*
7. *(camera button → a price-tag photo)*
   or, without a photo: `اینجا ۱۰۵ میلیون می‌دن، منصفانه‌ست؟`
8. `یه گوشی سامسونگ A17، یه قاب براش و یه شارژر`
9. `نزدیک ترین موبایل فروشی کجاست`
   *(tap a shop name to open its page)*
10. *(change the location to **ونک** to show the coverage note)*

## Extras, if there's time

- `آیفون ۱۳ بهتره یا سامسونگ A55؟`: a spec comparison
- `نات اکتیو یعنی چی؟`: a one-line explanation

Run through them once before recording: the answers vary a bit between runs.
